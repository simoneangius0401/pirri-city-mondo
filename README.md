# Pirri City — dati del mondo grande

Secondo sito del gioco Pirri City (https://simoneangius0401.github.io/pirri-city-gioco/):
qui stanno i pacchetti dei quadrati del mondo grande (mondo/b_*.json) e le loro foto dall'alto (mondo/img/),
perche' un solo sito GitHub Pages arriva al massimo a circa 1 GB.

Dati: OpenStreetMap (ODbL), Overture Maps, foto dall'alto e quote come indicato nei crediti del gioco.
